# 🌤️ そらくる 〜SoraQru〜

今日・明日（48 時間）の天気と気温、気圧の変化の目安を、時間ごとの色の帯でひと目で見るツール。名前は「そらくる」（空のようすが先に来る）。英字は SoraQru（「く」を Q にする。おくるん＝OQRN・つづく＝TuZuQ と同じ作り方）。キャッチコピーは「空のごきげん、先どり」。GitHub Pages でそのまま動く静的サイトで、サーバーは使わない。

公開URL: https://katsuan.github.io/soraqru/ （2026-10-23 公開。ConneQt の一覧・ポートフォリオにも載せた）

完全に無料で、広告・有償の案内は出さない。天気は [Open-Meteo](https://open-meteo.com/)（無料・鍵なし）だけを使う。

## できること

- 📍 開くと現在地（位置情報）の天気。断られた・わからないときは「地点を足す」を開き、地名で探すか、覚えた地点を選ぶ
  - 現在地の見出しは市区町村の名前（例：📍 倉敷市）。地名を調べるときだけ、100m くらいに丸めた位置を国土地理院の逆ジオコーダーに送り、市区町村のコードを `data/muni.json` で名前にする（`js/place-name.js`。残さない）。1km に丸めた位置で調べると、市のさかいの近くでは、となりの市区町村になることがあったため（倉敷市林 → 岡山市南区）
- ☀️ いま：天気・気温・その日の最高と最低、いまの気圧（hPa）と3時間後に上がるか下がるか、気圧の変化の目安
- 🗓 今日・明日：天気・最高と最低・降水確率、気圧の変化の目安の帯（1時間ずつ 24 こ。今日の過ぎた時間は薄く、いまの時間に枠）、注意の時間帯のまとめ（「12〜16時 注意（下がる）」）、1時間ごとの天気（横に送る。今日はいまの時刻から）
- 🌀 気圧の変化の目安（4段階）：3時間前とくらべて、気圧がどれだけ変わるか（上がっても下がっても）。1 hPa 未満＝通常（青 #7FA7D9）・2 未満＝やや注意（黄 #E8B931）・3 未満＝注意（橙 #F08A24）・それ以上＝警戒（赤 #E5534B）
  - 決め方と色は、KazoQ の予備（`q-kazoq/01_27_ZUTOOL_GATEWAY_METEO.js`）と SQriptable の気圧カードと同じ。頭痛ーる（zutool）の中身は使わない
  - 画面の言葉は「気圧の変化の目安」。体調の予測・診断ではないことを、開閉の中に書いている
- 🏠 地点：地名で探す（Open-Meteo の地名さがし。「名古屋」と「名古屋市」をいっしょに探し、日本を先・人の多い順）か、いまの場所を足す。しるし（絵文字）と呼び名（実家・職場など）をつけて 8 か所まで。上の丸いボタンで切りかえ。「覚えた地点」で呼び名を直す・消す（すぐ消して「元に戻す」で戻せる）・この端末の記録をすべて消す
- カードで送る（おくるんのマーク）：おくるんのお知らせカード（`OQRN.cardUrl`）に、1日1枚で、天気と注意の時間帯（1つずつの行）を渡す。押すと下からシートが出て、送る日（今日・明日）を、カードの見本つきの札のチェックで選ぶ（さくせん盤の送る画面と同じ形。見本は LINE の見た目なので暗い表示でも明るいまま、2枚は高さをそろえる）。夜（18時から）は明日だけを先に選んでおく。2枚なら2枚目を `card=` に入れ、おくるんが横に並べて1通で送る。今日の分は、いまの時刻からの時間帯だけ。色はロゴの群青（#3A56D6）。カードごとに出典も入れる。ボタンは「🌤️ そらくるで見る」。流入口は `from=soraqru`
  - 地名で探した地点だけ、ボタンのリンクに場所を入れる（`?at=35.18,136.91&name=名古屋`）。受けとった人は同じ地点が見られ、「＋ この地点を覚える」で覚えられる。現在地・いまの場所から足した地点は、リンクに場所を入れない
- 📡 電波がないとき：前に開いたページは `sw.js` で開ける。天気は覚えている結果を「◯時◯分の情報です」と出す
- 出典：ページのいちばん下に「天気データ：Open-Meteo.com（CC BY 4.0）」

週やカレンダーの並びは作っていない（作るときは月曜はじまりを既定にして、切りかえられるように）。

## ほかのツールから開く・ほかのツールとつなぐ

- 開き方：`?at=35.17,136.88&name=名古屋` か `?q=那覇`（場所の名前。Open-Meteo の地名さがしで、いちばんそれらしいもの）に、`&date=2026-11-01&hour=13`（見たい日・時刻。なくてもよい）と `&from=yuqsaki`（開いたツール：ゆくさき・さくせん盤・くらぶボット・KazoQ）
  - 見たい日が今日・明日なら、その札に「📅 予定」の印と時刻の枠。それより先（16日先まで）は、16日ぶんの予報を聞いて（端末には覚えない）、その日の札を一番上に。過ぎた日・16日より先は案内だけ
  - 上の案内は「ゆくさきで開いた「那覇」の 10/31（土） 13時ごろの天気を見ています」（知らないツールの名前は使わない）
- 使っているツール：ゆくさき（しおりの行き先・日にち）・さくせん盤（試合の場所・日時）・くらぶボット（天気の一覧の地点）・KazoQ（天気の知らせのカード）
- くらぶボット（確かめ中）：たたみ欄「🔔 天気の知らせを LINE で受けとる」の「⚙️ くらぶボットとつなぐ」に、ボットの URL（合言葉なし）を入れる（Q キットの `shared/qlove-bot.js`、localStorage の `qlove:bot`）。つないだ人には「🔔 この地点を、くらぶボットの知らせに足す」が出て、押すとボットのトークに「📍 地点を足す 35.17,136.88 名古屋」の文が入った状態で開く（ボットの LINE の ID は、URL の確かめ（ping）で聞く。端末には残さない）。たたみ欄は `?preview=notify` か、もうつないでいる人だけに出す

## Open-Meteo の使い方

- 無料版は、商用でない使い方だけ（広告・課金をしない）、1日 1 万回など IP ごとの上限、CC BY 4.0 の出典が要る。このページは完全無料・出典ありで使う
- 呼ぶのは使う人のブラウザから直接（サーバーを通さない）。上限は使う人ごとにかかる
- 同じ地点の結果は 1 時間ほど端末に覚えて、聞きなおさない（ページを開きなおしても、地点を切りかえても）。時刻が変わったら描きなおし、1時間たっていれば聞きなおす
- 聞く場所は 0.01 度（1km くらい）に丸める
- 聞くもの：`hourly=pressure_msl,temperature_2m,weather_code,precipitation_probability,is_day`・`daily=weather_code,temperature_2m_max,temperature_2m_min,precipitation_probability_max`・`timezone=auto`・`past_days=1`（0時の「3時間前」に前の日の夜が要る）・`forecast_days=3`（電波がないまま日をまたいでも、今日・明日が残る）
- 返事が壊れている・欠けているときは、読めるところだけ使う（気圧が1つもなければ使わない）。日ごとの天気がなければ、1時間ごとの値から作る

## 記録の置き場所

この端末（ブラウザ）の localStorage の `soraqru:v1` だけ。サーバーには送らない。読むときは形を確かめ、壊れたところは捨てる（`js/store.js` の `parse`）。

- `places`：覚えた地点 `[{ id, name（12字まで）, emoji, lat, lon, src（"search"＝地名で探した・"gps"＝いまの場所） }]`（8 か所まで）
- `current`：見ている地点（`"here"`＝現在地、または places の id）
- `here`：前に取れた現在地（0.01 度に丸めたもの。次に開いたとき、先に前の結果を出すため）と、その地名（`name`。`named: 2` は 100m くらいの位置で調べた印。印のない前の名前は調べなおす）
- `cache`：地点ごとの天気 `{ "35.17,136.88": { at, data } }`（新しいものから 10 か所。3日より古いものは捨てる）

はじめての人への使い方（1回だけ）は、Q キットの `line-share:tip:soraqru`。

## 天気の知らせ（くらぶボット。確かめ中）

雨・気圧の変化・気温の大きな変わり目がある日だけ、決めた時間に LINE で知らせる。くらぶのツール共通の「くらぶボット」（`~/GitHub/q-qlove-bot`。使う人が配布用シートをコピーして持つ）の、機能「☁️ 天気」として作った。気圧の目安は、くらぶボットのテストで、このリポジトリの `js/meteo.js` と同じ答えかを確かめている（`js/meteo.js` を変えたら、くらぶボットの `npm test` も動かす）。

- そらくるの画面のたたみ欄「🔔 天気の知らせを LINE で受けとる（くわしい人向け）」から、くらぶボットの手順書へ。確かめがすむまで、たたみ欄は `?preview=notify` で開いたときだけ出す
- 知らせのカードの「🌤️ そらくるで開く」は、その地点が開くリンク（`?at=…&name=…&from=qlovebot`）

## アイコン・ロゴ・OGP

`python3 tools/icon.py` で作る（図形を描く部分は、となりのおくるん（`~/GitHub/q-oqrn`）の `tools/brandkit.py`）。

- Q は晴れ間：輪がまるごと黄色い太陽、右下へのびるしっぽは太陽にかかる白い雲。アイコンには太陽のまわりに短い光（ロゴの Q は、字と同じ大きさで読めるよう、輪と雲だけ）
- 色はすみれ色がかった空から群青（ほかの Q のツールと重ならない空の色）
